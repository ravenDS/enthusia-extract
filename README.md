# Enthusia Extract
Unpack .BIN files from Enthusia Professional Racing (PS2)

**Usage:**
- Extract ISO contents of Enthusia Professional Racing (**NTSC, SLUS 20967**) to a folder
- Run the following command: **`python3 enthusia_extract.py <path-to-folder>`**
- _Optional_: Import `.pkd` model files into Blender with [**Enthusia Importer**](https://github.com/ravenDS/enthusia-importer/)
